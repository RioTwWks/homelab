# Фото- и видеохранилище (Immich)

Аналог Google Фото: веб-интерфейс, мобильные приложения (iOS/Android), автоматическая загрузка с телефона, альбомы, распознавание лиц, поиск по дате/месту, общий доступ.

## Запуск

```bash
docker compose --profile photos up -d
```

Поднимаются **immich-server**, **immich-machine-learning**, **immich_redis**, **immich_db**. Образ ML по умолчанию зафиксирован на **v1.141.1** — тег `release` в новых сборках даёт падение (SyntaxError в gunicorn, [issue #22592](https://github.com/immich-app/immich/issues/22592)). При выходе исправления можно задать `IMMICH_ML_VERSION=release`. Первый запуск может занять 1–2 минуты.

## Доступ

- **Локально:** http://localhost:18083 (порт задаётся `IMMICH_PORT` в `.env`).
- **Из сети / снаружи:** см. раздел «Доступ извне».

При первом заходе зарегистрируйте учётную запись — первый пользователь становится администратором.

## Переменные окружения (.env)

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `IMMICH_PORT` | Порт веб-интерфейса на хосте | 18083 |
| `IMMICH_VERSION` | Версия образа server (тег) | release |
| `IMMICH_ML_VERSION` | Версия образа ML (тег). Рекомендуется v1.141.1, т.к. release ломается (#22592) | v1.141.1 |
| `IMMICH_DB_USERNAME` | Пользователь PostgreSQL | postgres |
| `IMMICH_DB_PASSWORD` | Пароль PostgreSQL | **рекомендуется сменить** |
| `IMMICH_DB_DATABASE` | Имя БД | immich |

Перед первым запуском задайте надёжный `IMMICH_DB_PASSWORD`.

## Доступ извне (веб и мобильные приложения)

Как в Google Фото — загрузка с телефона и просмотр с любого устройства.

1. **Доступ по IP в локальной сети**  
   - С телефона/планшета в той же Wi‑Fi: откройте в браузере `http://IP_СЕРВЕРА:18083` и войдите или зарегистрируйтесь.  
   - Мобильное приложение Immich (App Store / Google Play): в настройках укажите URL сервера `http://IP_СЕРВЕРА:18083`.

2. **Доступ из интернета**  
   - Рекомендуется вынести Immich за **обратный прокси** (Caddy, Nginx, Traefik) с **HTTPS**.  
   - Настроить домен (например `photos.mydomain.com`) и в приложении указать `https://photos.mydomain.com`.  
   - Без HTTPS многие функции (автозагрузка в фоне, push) в мобильных приложениях работают ограниченно или требуют разрешения «небезопасного» соединения.

3. **Мобильные приложения**  
   - **Immich** в [App Store](https://apps.apple.com/app/immich/id1613912486) и [Google Play](https://play.google.com/store/apps/details?id=app.alextran.immich).  
   - В приложении: «Server URL» = адрес вашего сервера (например `http://192.168.1.10:18083` или `https://photos.mydomain.com`).  
   - Включите автозагрузку — фото и видео с устройства будут синхронизироваться в ваше хранилище.

## Возможности

- Загрузка фото и видео через веб и приложения.  
- Хронология, альбомы, карта (по EXIF GPS).  
- Распознавание лиц и объектов (контейнер immich-machine-learning).  
- Поиск по дате, месту, людям.  
- Общие альбомы и ссылки для гостевого доступа.  
- Резервное копирование: данные в томах `immich_upload` и `immich_db_data`; при необходимости настройте бэкапы (например, скрипты или Duplicati).

## Данные и тома

- **Медиафайлы:** том `immich_upload` (в контейнере `/data`).  
- **БД:** том `immich_db_data`.  
- **Кеш ML-моделей:** том `immich_ml_cache`.

## Альтернативы

- **PhotoPrism** — веб-ориентированный, без официальных мобильных приложений, подключается к существующим папкам.  
- **Pigallery2** — лёгкий веб-галерея по папкам на диске.

Для сценария «как Google Фото» с вебом и мобильными приложениями Immich — основной вариант в плане.
